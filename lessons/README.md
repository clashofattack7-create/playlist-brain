# 📚 LESSONS — durable, dedup'd lessons distilled from the journal

**Naming:** `<NN>-<slug>.md` where NN increments over the current count; check `lessons/` first —
**never write the same lesson twice** (merge or update the existing file instead).

**Template:**

```md
# Lesson <NN> — <short title>

- **Date:** <YYYY-MM-DD>
- **Class citation:** <exact class, e.g. How To Place Stop-Loss class-12>
- **Rule as taught:** <one line>
- **Observed:** <what actually happened, from journal\<date>.md>
- **Lesson:** <one durable sentence>
- **Status:** CONFIRMED | OPEN QUESTION
  (OPEN QUESTION = contradicts the rulebook — flag it in the next morning's read; never silently
  rewrite the rule.)
```

Rules:
1. Lesson must trace to a real journal entry — no journal, no lesson.
2. Keep the **closed-corpus line**: lessons are observed results, not new market theory.
3. If a lesson flips over time, edit its Status/evidence — never delete the history line.
