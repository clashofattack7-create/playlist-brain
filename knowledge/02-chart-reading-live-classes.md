## Key recurring rules (as taught across the series)
1. Read the chart **before** the market opens: prev close, gap, levels, plan.
2. Compare **Nifty + Bank Nifty + Sensex** — divergence is information.
3. Mark levels, not indicators: swing highs/lows, round numbers, previous-day close.
4. Trade the plan; if the opening invalidates it, write a new plan.
5. Small size, fixed risk, stop-loss always — the "everything right but losing" class pins losses to breaking these.
6. Practice daily — chart reading is a skill trained every session.
