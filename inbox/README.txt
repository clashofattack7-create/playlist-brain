INBOX — how to send the Playlist Brain files/requests
==================================================
Drop ANY file here (screenshot .png/.jpg, option-chain JSON, CSV, notes .txt).

Then in the chat:
  - type  @playlist-brain/inbox/FILENAME   (the @ menu completes it for you)
  - or for images: drag & drop the image directly onto the chat page
    (a drop overlay appears; thumbnails show in a rail; press Send).

What the Brain does with it:
  - option chain screenshot / JSON  -> OI map merge into the daily plan
  - chart screenshot                -> chart read (bias/entry/SL/target)
  - TXT/CSV data                    -> read & fold into analysis

Cleaned up file? Keep old ones in raw/ if you want history; inbox is for
"please read this now" items only.
