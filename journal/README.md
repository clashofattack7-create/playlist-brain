# 📔 JOURNAL — the brain's day-by-day outcome log

**Naming:** `YYYY-MM-DD.md` (one file per trading day, append-only history).

**Template (fill what exists; mark the rest —/not given):**

```md
# 📔 <YYYY-MM-DD> — session journal

## Plan recap (from knowledge\<NN>-plan-<date>.md)
- Bias: …
- Levels/Entry/SL/Target: …

## What actually happened
- Open: NIFTY … | BANKNIFTY … | SENSEX … (gap direction + size)
- Day: high/low/close per index, which levels broke
- OI story (if seen): walls that held / died

## My trades (only what I actually did)
| Time | Side | Instrument | Entry | SL | Target | Qty | Exit | Result ₹ |
|---|---|---|---|---|---|---|---|---|

## Plan vs actual
- Did the plan work? Which rule was right / wrong?
- One-line verdict with class citation: e.g. "PDC held as support (Previous Day Closing Price Class-1)".

## Lesson (write into lessons\<NN>-<slug>.md if durable; else leave OPEN QUESTION)
```

Rule: record **only** trades the user actually reported. Never invent fills or results.
